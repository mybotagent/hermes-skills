## logs/index.md 행 추가: python 인서트 방식 (P18 회피, 2026-10-28 신규 검증)

SKILL.md 2c-ter는 `patch` 도구로 행 추가를 안내하지만, `||` double-pipe 테이블에서 patch는
P18 self-inflicted 변형(leading pipe 중복/누락) 위험이 있다. **python 인서트**가 더 안전하고 검증이 쉽다.

```bash
cd ~/.hermes/wiki/logs
python3 - <<'PYEOF'
p = 'index.md'
lines = open(p).read().split('\n')
new = "|| 10-28 21:00 | Daily Wiki Auto-Refresh — ... | [2026-10-28-2100](2026/2026-10-28-2100.md) |"
# 기준 행(직전 날짜)의 prefix를 그대로 복사해 형식 일치 보장
i = [k for k, l in enumerate(lines) if l.startswith('|| 10-27 21:00')][0]
lines.insert(i, new)
open(p, 'w').write('\n'.join(lines))
print("inserted at", i + 1)
PYEOF
# 검증: 인접 행 prefix 비교 (cat -A) + triple-pipe 0건
sed -n '10,14p' index.md | cat -A | cut -c1-45
grep -c '^|||' index.md
```

장점:
- 인서트 위치가 행 번호로 확정 → P20 fuzzy mis-anchor 원천 차단
- `split('\n')`/`join('\n')`으로 기존 파일 바이트 구조 보존 (P18 방지)
- 새 행 prefix(`||`)를 기준 행에서 그대로 복사 → triple-pipe 0건 보장

주의: 마지막 행이 개행 없이 끝나면(`\ No newline at end of file`) join 후 개행 처리가 달라질 수 있음 —
`git diff`로 확인.
