## 세션 노트 prepend — partial-read 경고는 치명적이지 않음
- `read_file(path, limit=6)`처럼 부분 읽기 후 patch를 시도하면 patch 도구가 `_warning: ... was last read with offset/limit pagination (partial view)` 경고를 냈다.
- **앵커가 날짜-유일 헤더(`## 2026-10-22 (21:00 KST) — ...`)이면 부분 읽기 상태에서도 patch는 정상 적용된다** — 헤더는 파일 전체에서 유일하므로 mis-anchor 위험이 없다. 이번 실행에서 10-23 섹션이 정확한 위치(5행, 맨 위)에 삽입됨을 확인.
- 다만 P20/P26 원칙상 **전체 읽기가 기본**이고, 부분 읽기는 "앵커가 날짜 헤더로 확정된 경우"에만 허용.
- patch 후 검증: `grep -n '^## ' | head -6` (내림차순 순서), `grep -c '^## 2026-10-23'` = 1, `grep -c '^|- '` = 0.
