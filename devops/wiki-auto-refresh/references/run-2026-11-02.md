## 신규 학습: logs/index.md 신규 월 섹션 신설

2026-11 로그가 처음 등장하면서 `### November` 섹션이 필요했다.

**잘못된 방법**: 기준 데이터 행(`|| 10-30 21:00`) 앞에 `### November` + 테이블 헤더를 삽입
→ October 테이블 헤더가 November 뒤로 밀려나 **헤더-섹션 순서 역전** 발생.

**올바른 방법**: **월 섹션 헤더 위치(`### October`) 앞에** 새 월 섹션 블록 삽입.
```python
oct_idx = [k for k,l in enumerate(lines) if l.strip() == '### October'][0]
lines[oct_idx:oct_idx] = ["### November", "", "|| Date | Event | File |", "||:-----|:------|:-----|", newrow, ""]
```
복구: `git checkout index.md` → 재시도 (logs는 별도 repo이므로 submodule pointer와 무관).

검증: `sed -n '5,20p' index.md | cat -A | cut -c1-50` → 두 섹션 모두 `||` prefix 일치, `grep -c '^|||'` = 0, logs-index-link-audit broken 0 / notref 0.
